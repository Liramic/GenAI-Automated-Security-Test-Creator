# GenAI Automated Security Test Creator 

**Author:** Liron Amihai  
**Supervisor:** Dor Levy  
**Organization:** Cellebrite

## 📌 Overview

`Irius_testcases_autogen` is a codebase designed to integrate with a threat modeling service—specifically [IriusRisk](https://www.iriusrisk.com/)—to automate the generation of meaningful, context-aware test cases for validating security countermeasures.

## 🎯 Purpose

This project aims to:

1. **Generate simple, context-rich test steps** that allow even non-technical users to validate the existence and effectiveness of security countermeasures.
2. **Provide meaningful names and explanations** for countermeasures, enhancing clarity and traceability.
3. **Automatically produce test code** capable of validating the implementation and behavior of countermeasures.
